# Astro: sitios web rápidos y modernos

Astro es un framework pensado para construir sitios web con mucho contenido y
cargar únicamente el JavaScript que cada página necesita. Esto permite ofrecer
una experiencia ágil sin renunciar a las herramientas modernas del desarrollo
web.

## Menos JavaScript en el navegador

Por defecto, Astro genera HTML en el servidor y lo envía listo para mostrarse.
Los componentes interactivos se pueden agregar como islas: cada uno se hidrata
solo cuando hace falta. Así, un buscador puede ser interactivo sin obligar al
resto de la página a cargar código innecesario.

## Trabaja con tus herramientas favoritas

Puedes escribir componentes Astro y, cuando el proyecto lo requiera, integrar
React, Vue, Svelte u otros frameworks. Esta flexibilidad facilita reutilizar
componentes existentes y elegir la herramienta adecuada para cada necesidad.

## Contenido organizado

Las colecciones de contenido permiten mantener artículos, documentación y otros
recursos en archivos Markdown con metadatos validados. El resultado es contenido
fácil de editar y una estructura que ayuda a encontrar errores antes de publicar.

Astro es una buena opción para blogs, portafolios y sitios de documentación:
combina páginas ligeras con una experiencia de desarrollo familiar y extensible.
