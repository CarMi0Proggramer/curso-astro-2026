# Curso Astro

Proyectos construidos en vivo durante los de mi Curso de Astro.

📺 [Playlist del curso](https://www.youtube.com/playlist?list=PLVQhbE4IMjIw)

## Proyectos

| # | Proyecto | Descripción | Stack |
|---|----------|-------------|-------|
| 01 | [Portfolio](./01-portfolio) | Sitio de portafolio personal | Astro |
| 02 | [Blog](./02-blog) | Blog con content collections, SEO y sitemap | Astro, astro-seo, sitemap |
| 03 | [Ecommerce](./03-ecommerce) | Tienda con frontend y CMS headless | Astro, Vue, Stripe, Strapi |

## Uso

```bash
cd 01-portfolio   # o el proyecto que quieras
npm install
npm run dev
```

El proyecto `03-ecommerce` se divide en `app` (frontend Astro) y `cms` (Strapi).

## Requisitos

- Node.js 22+
